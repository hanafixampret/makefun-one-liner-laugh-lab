# One-Liner Laugh Lab

One short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock.

Entry: "It was on the floor. My entire job is the floor. I fail to see the issue."

`main.ts` (Node 22, stdlib-only) writes the line to `/output/entry.txt` and verifies the gate (1–200 characters, one line, not whitespace-only) with a round-trip check.
